# Motor 33 — YouTube Studio publish sheet

One sheet per video, saved as `m33-studio.md`. Every field filled, in English (the channel's
language), ready to copy into YouTube Studio. Field names follow YouTube Studio; if the creator's
Studio shows different labels, record the difference.

## Details

| Field | Rule |
|---|---|
| **Title** | The locked M22 title, exactly. |
| **Description** | The M22 description, with the "real person behind the channel" line (see `7-cadastro-canal.md`) and: the first two lines as the search snippet; **chapters** from the measured final timings (first at `00:00`, at least 3, each ≥ 10 s — the format YouTube needs to show chapters); **SOURCES & NOTES** with every official source, publication date and URL; the AI line ("Narration and some visuals are AI-generated. Research, sources and script are original."); music attribution if any Creative Commons track was used; "This video is for information and education. It is not financial or career advice." |
| **Thumbnail** | The ThumbLab file made from the thumbnail brief — **3 variants in "Test & compare"** (winner by watch time). |
| **Title test** | The M22 Top 3 titles in "Test & compare" when available; otherwise the champion title. |
| **Playlist** | The playlist for the video's editorial line (create it if it doesn't exist). |
| **Audience** | **"No, it's not made for kids"** (always — adult audience 25–54). Age restriction: No. |
| **Paid promotion** | Yes only if the video has a sponsorship or paid placement; otherwise No. |
| **Altered or synthetic content ("AI use")** | Apply policy §5: **Yes** if any photorealistic AI image or video appears; stylized-only → decide in the report, Yes when in doubt. Record the reason. |
| **Automatic chapters** | Off (we provide our own). |
| **Featured places / automatic concepts** | Off unless useful. |
| **Tags** | Up to ~15: spellings, names and terms people actually type (from M11/M22 research). No unrelated tags (against YouTube policy). |
| **Language / caption certification** | Video language: English. Captions: upload the final SRT if available, else YouTube auto + review. |
| **Recording date and location** | Leave blank. |
| **License** | Standard YouTube License. |
| **Distribution** | Everywhere; allow embedding: Yes. |
| **Shorts remixing** | Allow video and audio remixing (default) unless the creator prefers otherwise. |
| **Category** | Education (or News & Politics only if the video is primarily news). |
| **Comments** | On; hold potentially inappropriate comments for review. |

## Video elements

| Field | Rule |
|---|---|
| **Subtitles** | Final SRT (English), checked against the locked narration. |
| **End screen** | Last 10–20 s: one best-for-viewer video + subscribe element. The narration's closing question plays over it — no extra spoken CTA. |
| **Cards** | 0–2, only where a related ProfitMoments video helps the viewer. Never in the hook. |

## Visibility

Private upload → creator's final review → **Schedule** or **Public**, only with the creator's
explicit authorization. Suggested time from DarkMetrics' "day and time" data when available.

## Policy checklist (PASS / FAIL before handing the sheet over)

- [ ] AI disclosure decided per policy §5 and recorded.
- [ ] Made for kids = No.
- [ ] No third-party logos, footage, screenshots or music without rights (policy §2).
- [ ] Every number on screen and in the description matches the source map.
- [ ] No prohibited claim in title, thumbnail, description, captions or visuals.
- [ ] Description includes all sources with dates and URLs, the AI line and the disclaimer.
- [ ] Chapters valid (00:00 first, ≥ 3, ≥ 10 s each) and match the chapter cards.
- [ ] Tags relevant only.
- [ ] Duration above 8:00 (measured).
- [ ] AI-persona rule: the narrator never presents as a person or expert; no prescriptive financial
      advice; the "real person behind the channel" line is in the description (policy §6b).
- [ ] Mid-roll points at the chapter transitions (natural pauses).
- [ ] Originality: the video's structure and visuals vary from previous uploads (inauthentic-content
      policy).

## LinkedIn post (draft for the creator)

3–6 lines in the creator's own voice: one honest insight from the video, the question it raises,
and the link. No hype, at most 3 hashtags.
