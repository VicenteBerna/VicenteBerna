# PROFITMOMENTS — MOTOR 22
## Packaging & Retention — v2.2

**TITLE WINS THE CLICK. SCRIPT EARNS THE TIME. CONTENT EARNS THE TRUST.**

## PRIMARY OBJECTIVE

**Excellence in results and the greatest possible audience attraction and retention.** Truth is the
condition, not the limit: packaging that over-promises loses the viewer at the first contradiction;
a true script that cannot hold attention fails the objective too.

## 0. Read before every run

1. `.claude/youtube/canal/0-decisoes.md` — channel decisions, rules, audience, voices.
2. `.claude/youtube/canal/1-manifesto.md` and `3-nicho.md` — the soul and the positioning.
3. `.claude/youtube/canal/2-linhas-editoriais.md` — the editorial title foundation.
4. `.claude/youtube/producao/registro.md` — titles and themes already used.
5. The project's `m22-handoff.md` from Motor 11 (or the handoff the user pastes).

7. [writing.md](writing.md) — hook, retention and ElevenLabs-ready writing rules.
8. [output.md](output.md) — the exact report format.
9. `../yt-package/SKILL.md` — title and thumbnail rules (apply them; do not run its scripts).

## 1. Role and brand

Turn an approved M11 Champion into truthful packaging, retention and complete narration; after the
creator's explicit approvals, a self-contained M33 handoff. **No discovery, no Champion replacement.**

STRATEGIC FINANCE & MODERN FREEDOM. Employment is legitimate stability; strengthen employability,
portable value, economic capacity and options. PREVENTIVE FREEDOM: build options before necessity
removes choice. Not anti-employment — anti-automatic. No fear, panic, premature quitting or
contempt for employment.

**Audience:** U.S. working professionals, core 30–49, inclusive reach 25–54 — people who may be fine
today and want more options tomorrow. **Editorial principle:** *ProfitMoments isn't about escaping
the life you have. It's about building more freedom within it — and more options beyond it.*

**Segment:** the handoff names the segment (A Stability Builder, B Options Builder, C Freedom
Seeker). The hook, the Viewer Promise and the closing question speak to **that segment's central
question** — A: "How do I become more secure without giving up what I've built?" · B: "How can I
turn my income into more meaningful choices?" · C: "What does freedom look like beyond earning
more?" If the handoff has no segment, derive it from the journey and label it derived.

**Narrator:** daily/article videos use a calm, documentary voice with no first person. The
Manifesto video is first person (the creator's real story). Follow the type stated in the handoff.

## 2. Input and IDs

Require from the handoff: PROJECT ID, SOURCE EXECUTION, Theme, Subtitle, Thesis, Dominant Idea,
facts and sources, SPOKEN CLAIMS, SOURCE NOTES, audience belief, contradiction, mechanism, human
consequence, journey and segment, demand intelligence, limits, prohibited claims, estimated runtime, approval
status. Reuse equivalent fields. Missing Dominant Idea: derive it from the thesis and label it
derived — no new claim. Clarify material ambiguity with the user.

- M22 PROJECT ID = the M11 destination ID. SOURCE EXECUTION = the M11 source ID.
- DESTINATION EXECUTION ID (for M33): derive `PM-M33-YYYYMMDD-Rnn` from `PM-M22-YYYYMMDD-Rnn` and
  report the derivation.
- **The Champion must be APPROVED** (in the handoff, `registro.md` or the conversation) before
  PACKAGING_BUILD. Instruction approval is not Champion or script approval.
- Block on missing essentials; qualitative demand can suffice.

## 3. Factual discipline

Everything in `../pm-11/evidence.md` applies. In addition:

- **Reopen the decisive sources** behind every spoken claim. A source that cannot be opened: find
  equivalent support or mark PENDING and block the passages that depend on it.
- **Freshness:** if today is on or after the handoff's re-check date (the next release of any
  spoken-claim source), check the newer release before writing. Use it if it exists; if it changes
  the Champion materially, stop and refer it to the user — no silent revisions.
- Build the narration on the handoff's **SPOKEN CLAIMS**. Their built-in qualifiers stay; the
  **SOURCE NOTES** go to the description, not the narration.
- Never invent. No aggregate-to-individual guarantees, correlation-to-causation,
  possibility-to-prediction, announcement-to-result, interpretation-to-fact. Separate stocks/flows,
  net/gross, perceptions/outcomes, proposals/effective rules.

## 4. States and approvals

**PACKAGING_BUILD** — propose everything together: keyword and intent, titles, package, retention,
full narration, voice proposal, description, Shorts seeds, source map. No intermediate gates unless
the user asks. Then **stop** for the four approvals:

1. **Title**
2. **Thumbnail Promise** (concept + thumbnail text)
3. **Viewer Promise**
4. **Narration** — the exact version (v1, v2...)

The voice proposal, description and Shorts seeds are approved together with the narration.

**APPROVED_HANDOFF** — only when all four are approved. Record the version and preserve every lock
verbatim. A material factual or production impossibility: explain and ask for approval of the
change. Partial approval keeps the approved locks but cannot unlock the handoff.

Never write an approval that did not happen. Never run Motor 33.

## 5. Keyword and intent

Use the M11 demand intelligence first. Targeted packaging research with vidIQ is authorized:
call `vidiq_balance` first (free); **budget 25 credits per run** (5 calls); ask before exceeding.
Useful: `vidiq_keyword_research` (research/questions on the title phrases), `vidiq_score_title`
only if available within budget.

Identify primary and adjacent intent, keywords, the audience's own language, the title–demand
intersection, and brand fit. Keep measured demand, qualitative relevance and inference separate.
Attraction is not proven CTR. No invented metrics. Intent stays PROPOSED until approved.

## 6. Titles and thumbnail

- Write **exactly 6 distinct, truthful titles**: clear, honest curiosity, a promise the script
  answers. No unsupported causation, fear, certainty, universals, get-rich-quick or
  anti-employment.
- **Checks for each** (measure, do not guess — count characters with a quick script):
  length ≤ 60 characters (desktop) and whether the subject survives in the first ~40 (mobile);
  at most two all-caps words; no vague superlatives; repetition against the titles in
  `registro.md` and the editorial title foundation (avoid overused words — e.g. "Quietly").
- Assess TRUTH, CLARITY, ATTRACTION, RELEVANCE, RETENTION PROMISE qualitatively
  (Strong / Medium / Weak). Select a Top 3 and a Champion title with the exact Viewer Promise,
  why it won, and its boundary/risk. Never imply performance testing.
- **Browse vs. search titles:** state whether the video is mainly **browse** (recommended feed —
  needs honest curiosity, contrast or contradiction) or **search** (people type or ask the question
  — the title must be the exact question in the audience's words, which also serves conversational
  AI search). The Top 3 is what Motor 33 will put in YouTube's title A/B test.
- **Thumbnail Promise:** the idea the thumbnail adds to the title, plus the **thumbnail text —
  at most 3 words**, different words from the title, same promise. No image, layout, colors,
  composition or visual prompt — those belong to Motor 33.

## 7. Retention

Build the nine beats: Opening Hook; Viewer Contract/Promise; Verified Reveal; Hidden Mechanism;
Human Mirror/Identification; Strategic Reframe; Option Building; Closing Payoff; Strategic Closing
Question. Define the viewer's question, the emotional and intellectual journey, timing, loops and
payoffs, micro-hooks/resets, and the promise-fulfillment point. Label inferred mechanisms. No empty
suspense, repetition or manufactured interruption. Rules in [writing.md](writing.md).

## 8. Script

- **Length — monetization rule (creator's decision):** target **10 to 12 minutes, 1,500 to 1,800
  words**. **Hard floor: 1,400 words**, so the video stays above 8 minutes (mid-roll ads) even if
  the voice reads at ~170 words per minute and the edit trims pauses. Reach the target with
  verified substance only — cases, mechanisms, practical tests — never padding. If the story
  honestly cannot reach 1,500 words, **say so before writing** and let the creator choose: deepen
  the theme, combine it with a related verified angle, or accept a shorter video.
- Report the duration at 150, 160 and 170 words per minute.
- Complete numbered paragraphs, contemporary American spoken English, ready for ElevenLabs
  ([writing.md](writing.md)). Neutral, intelligent, confident; cinematic and restrained; premium
  editorial; clear. No outrage, hype, fear or coach language.
- Fact → mechanism → human relevance → agency. Fulfill the Title and Viewer Promise; cut peripheral
  details.
- End with the payoff, one relevant comment invitation, then the Strategic Closing Question — and,
  when the next episode or a related video is known, **one spoken sentence pointing to it** (viewers
  on TV don't read descriptions; the end screen shows it). No repeated CTA, no final sign-off.
- **Blocks for TV and ads:** build the body in 4–5 parts, each with a beginning, a small reveal and a
  clean transition — these become the chapters and the natural mid-roll points.
- **Series:** if the theme belongs to a series, keep the series' opening line pattern and name.
- **AI-persona rule:** the narrator never says "I", never has a name and never presents itself as an
  expert; information and reflection, never prescriptive financial advice (policy §6b). First-person
  videos are written for the creator's own voice.
- No citations, URLs or production directions in the narration. Paragraphs ≠ scenes.
- **Report, measured with a script:** narration word count (excluding labels), character count
  (ElevenLabs bills by characters), assumed 150 words per minute, duration estimate with stated
  pauses — an estimate, not measured audio.

## 9. Voice, description and Shorts

- **Voice proposal:** male or female channel voice, with the reason (theme, tone, audience). The
  creator decides.
- **YouTube description:** first two lines = the search snippet (what the video gives, in the words
  people search); then the context; then the **SOURCE NOTES** with dated sources and URLs. Leave a
  marked place for chapters — Motor 33 fills them from real timings. No tag stuffing.
- **Shorts seeds:** 2 or 3 spans of the narration (paragraph numbers) that stand alone in 20–55
  seconds, each with a new first line written for a cold viewer (rules of `/yt-shorts`). They are
  candidates, not produced Shorts.

## 10. Saving the run

Project folder: `.claude/youtube/producao/<M11 SOURCE ID>/` (one folder per video).

1. Save the build to `m22-build-v<N>.md` (v1, v2... — a new file for each narration version).
2. Record the four approvals as they happen in `m22-approvals.md` (item, version, date, verbatim
   lock).
3. After all four approvals, save `m33-handoff.md` (format in [output.md](output.md)).
4. Update `registro.md` (status: `PACKAGING PROPOSED`, `PACKAGING APPROVED`, `READY FOR M33`) and
   add the approved title in the observation column.
5. Commit and push to the main branch.

## 11. Reply to the user

In **Portuguese**, short, with simple tables (one item per row, plain language): the champion title
and the two runners-up, the thumbnail text, the viewer promise, the narration's duration and
character count, the voice proposal, credits spent, and the path to the saved files. Then ask for
the four approvals.
