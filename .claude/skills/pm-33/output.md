# Motor 33 — Report format

Report in **English**, with a **Portuguese summary and the creator's next action at the top**, in
plain language and simple tables (one item per row). Only the stages that apply to this run; the
others marked PENDING with the artifact or action needed.

---

## RESUMO EM PORTUGUÊS

State of the production, what was done, what was found, and **the next action for the creator**
(what to open, what to click, what to send back).

| Etapa | Status |
|---|---|
| Preparação | ... |
| Plano de cenas e gráficos | ... |
| Primeira versão | ... |
| Controle visual | ... |
| Melhorias | ... |
| Controle final | ... |
| Thumbnail | ... |
| Cadastro no YouTube | ... |

## A. CONTROL SUMMARY
IDs, approved version, locks verified, state, approvals, platform facts used (with status).

## B. PRE-FLIGHT
Route, ratio, language, voice, pace, captions, music, style, evidence, media, budget, target and
measured duration, gaps.

## C. SCENE AND VISUAL PLAN / FIRST-PASS GUIDE
Scene table: # · start ≈ · narration excerpt · dominant idea · beat · treatment · source · movement ·
evidence label. Graphics list (file, fact IDs). Step-by-step guide: module · input · action · actor ·
expected output · check · next step.

## D. VISUAL QA
Per scene: timestamp · current · decision (KEEP / SWAP / UPGRADE TO AI VIDEO / SOURCE-DATA /
EXTERNAL) · reason.

## E. UPGRADES
Per upgrade: timestamp and narration · current → proposed · reason · benefit hypothesis · method or
prompt · cost and uncertainty · approval.

## F. FACTUAL CHECK
Script integrity (SRT/CSV vs. locked narration: differences found), on-screen numbers vs. source
map, labels, prohibited-claim check.

## G. FINAL QA
Editorial · factual · visual · audio/captions · technical (measured duration, resolution) — each
PASS / FAIL / PENDING / N/A with basis.

## H. THUMBNAIL AND PUBLISH SHEET
Pointers to `m33-thumbnail.md` and `m33-studio.md`, plus the policy checklist results.

## I. ECONOMICS
Estimated / reported / measured: duration, ElevenLabs characters, Flow credits and clips, vidIQ
credits, regenerations, creator time, corrections.

## J. VALIDATION / NEXT STEP
PASS / FAIL / PENDING / N/A with basis: locks and IDs; verified simplest workflow; actual draft and
QA; selective upgrades; dominant ideas; factual scope; no invented evidence; retention; authorized
budget; justified quality; honest cost and time log; actions actually performed. Fix FAILs; a
mandatory PENDING blocks dependent work. Upload and publication need the creator's explicit
authorization.
